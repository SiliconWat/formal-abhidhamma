**A repair to a round-1 repair, found by this round.** Round 1's A46 repair (`a46_plane_organs`) numbered the sense doors from 0 (nose = 2). The vocabulary's own doc says **doors 1–5, eye to body** (`sangaha/Citta.lean`), so the fine-material plane lacks doors 3, 4, 5. Fixed (`organAbsent`: `3 ≤ d`); its forbidden world now uses door 3. And **the generated `Vocab.lean` had dropped the docstring above a type**, so the encoders never saw the door numbering (the cause of A80's 0-versus-1 split); `vocab.py` now keeps it.
