# Correction to the input (2026-11-23): `Ranges.lean` regenerated after a parser fault in `cittuppada/`

This run's independent input, `dhatukatha/Ranges.lean`, is generated by `dhatukatha/ranges.py` from `cittuppada/CITTUPPADA.json` and was
committed before the registration (`9174cbc`). On 2026-11-23 a fault was found in `scripts/cittuppada.py`, the generator of that JSON.

**The fault.** On 39 lines of `abh01m.mul.xml` the question asks for a resultant class (*Katame dhammā abyākatā?*, e.g. L4109). The answer
first restates the wholesome class that is its condition, ending *… ime dhammā kusalā.*, and then gives the result in a second sentence on the
same line (*Tasseva … vipākaṃ …, tasmiṃ samaye phasso hoti…pe… avikkhepo hoti…pe… ime dhammā abyākatā.*). The parser read the first
sentence's list and ran on into the second. So each of the 39 records held one "term" made of the next sentence's words, and its list mixed
the two sentences. `Ranges.lean` inherited 21 of those fragments as keys.

**The repair.** The record for each of the 39 lines is now the class its question asks for, the second sentence: its feature words, its list
and its closing word (*abyākatā*). Every list ends at its closing formula, and `--validate` now refuses an item that is not a single term and a
record whose list does not close with the class its question asks for. Both checks fail on the file as it was committed, 39 times each.

**What changed in this run's input.** `Ranges.lean` lost the 21 fragment keys. No key was added and no element list changed. Each term's
range is read from the lists it is written in, as registered.

**What did not change.** The regenerated `Ranges.lean` re-checks this run's theorems: `dhatukatha/run.sh` passes, with
`every_in_scope_row_is_reproduced` and `the_in_scope_count` (38) as before and every break failing. `Classes.lean`, `Classes4.lean`,
`SampayogaMatrix.lean`, `SampayogaMatrix4.lean`, the Dhātukathā's own generated files and `sangaha/CanonAll.lean` are byte-identical to their
committed forms. This run's `PREREG.md`, `RUN.md`, verdict and refuter record are unchanged; the input as registered remains at `9174cbc`.

**Worth knowing.** One term's range in this run, `aññātāvindriyaṃ` (row `ind21`), is written in a list ONLY in one of these 39 result
sentences (L4413; L4421 defines the term and is not a list). A repair that kept the first sentence and dropped the second would have left it with no range, and the run's check fails then
(measured 2026-11-23: `CheckSampayoga2.lean` FAIL). Its range `[6]` was read through the fault before and is read from its own sentence now.
