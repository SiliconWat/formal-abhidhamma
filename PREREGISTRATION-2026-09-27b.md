# Pre-registration, second file — rung 3: the canon alone (L1), and Khmer against the CST

**Registered 2026-09-27 (America/Los_Angeles)** by Thon Ly · Miss Aquarius℠. It is pushed **before** any Dhammasaṅgaṇī text is read in either edition. Before this push, the only Khmer content read was the title line of the first two pages of volumes 77–80 (to find which volume is the Dhammasaṅgaṇī); no CST Dhammasaṅgaṇī file was fetched. This file cites `PREREGISTRATION.md` and never edits it. It is never edited itself.

## 1 · Dispositions of the first file's open predictions

- **P-FA1b is RETIRED, UNSCORED.** Its test ("narrow class") was never defined, and the rung 2 data have now been seen. Any definition chosen now would be chosen knowing the answer, so it cannot be re-registered on the same data.
- **P-FA3 cannot run as registered.** It compares editions at L2, which includes the *Abhidhammattha-saṅgaha*. That work is not part of the Khmer Tipiṭaka, and the only Khmer-script *Saṅgaha* held has the CST's paragraph structure in all nine chapters (43 · 60 · 74 · 55 · 102 · 65 · 53 · 43 · 75), so it is the CST transliterated, not an independent recension. P-FA5 below replaces it **at L1**, as a new prediction, not an edit.

## 2 · The object of rung 3

The **pada-bhājanīya of the first wholesome sense-sphere citta**: the Dhammasaṅgaṇī's list of what is present *"yasmiṃ samaye kāmāvacaraṃ kusalaṃ cittaṃ uppannaṃ hoti somanassasahagataṃ ñāṇasampayuttaṃ …"*, up to its closing clause. Editions: C = VRI `romn/abh01m.mul.xml`; K = the Buddhist Institute edition, volume 78 (Dhammasaṅgaṇī part 1), as transcribed.
